# Hackathon compliance matrix – status is NOT proof of full compliance

Mandatory criteria from the organizer's guide:

| Criteria | Evidence to produce | Status |
| --- | --- | --- |
| 1. Generative AI used | Live Gemini text generation, not hardcoded output | Not yet externally verified; code prepared |
| 2. SDG connection | SDG 10, possible target 10.2, user + problem + metric | Drafted; final report needed |
| 3. Deliberate prompts | Prompt files, documented choices, comparison results | 3 prompt templates prepared; comparisons needed |
| 4. Working end-to-end prototype | Paste unseen example, get model output and checklist | Code written; needs real API/UI smoke test |
| 5. Ethical assessment | hallucination, privacy, bias, prompt injection tests | Mitigations documented; real testing needed |

Required deliverables:

| Deliverable | Status |
| --- | --- |
| GitHub repository with code, prompts, working README | Local repo files ready; user must publish GitHub repo |
| Report 1–2 pages, PDF stored in repo | Markdown draft, needs results and PDF export |
| English presentation | Outline only, slide file pending |
| English ~5-minute demo video with on-screen working app | Not recorded; upload/published URL pending |
| On-time online submission before 19:00, 18 Oct 2026 | Not submitted |

**Sign-off only after actual user-side validation.** Never fill metrics without running tests. Quote presence is a mechanical check, not proof of interpretation correctness.
